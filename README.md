# Rose

A powerful and lightweight tool for **League of Legends** mod management.

## 📥 Download

Go to the [Releases](https://github.com/LeagueeToolKit/Rose/releases) page and download the latest version:

- `Rose_Setup.1.2.9.exe` — Windows installer (recommended)
- `Rose_Setup.1.2.9.zip` — Portable ZIP version

## 🚀 Features

- Simple and intuitive mod management interface
- Fast mod loading and applying
- Compatible with the latest League of Legends patches
- Lightweight with minimal system footprint

## 🛠️ Build from Source

```bash
cmake -B build -S .
cmake --build build --config Release
```

**Requirements:** Qt 6, CMake 3.16+

## 📂 Project Structure

```
src/        — C++ & QML source files
dist/       — Distribution scripts and tools
docs/       — Documentation and screenshots
```
